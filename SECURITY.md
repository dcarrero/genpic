# Security

genpic.com no longer exists, so there is no live service, user data or
payment flow left to compromise.

If you find a vulnerability in the code that could affect someone running
their own deployment, please report it privately through GitHub's
**Report a vulnerability** button (Security tab) rather than in a public
issue. Expect a best-effort response, not a guaranteed timeline.

If you deploy this code yourself, you are responsible for your own keys,
infrastructure and updates. The checklist in the [README](README.md#before-you-put-this-in-front-of-the-public)
covers the minimum.
